# Desafios Web — HTML & CSS

Repositório criado durante meu processo de aprendizado em desenvolvimento Front-end, reunindo uma sequência de desafios práticos desenvolvidos com **HTML e CSS**.

O projeto foi especialmente importante para consolidar meus conhecimentos de CSS por meio da construção de interfaces e da aplicação prática de conceitos de layout, estilização e responsividade.

## 🎯 Objetivo

Praticar e desenvolver fundamentos de desenvolvimento web, com foco principalmente em:

* HTML semântico;
* CSS;
* Flexbox;
* Grid Layout;
* Responsividade;
* Posicionamento e dimensionamento de elementos;
* Organização de estilos;
* Construção de interfaces a partir de referências visuais.

## 📚 Desafios

O repositório contém quatro desafios realizados durante o processo de aprendizado:

* **Desafio 1** — fundamentos de HTML e CSS
* **Desafio 2** — construção e estilização de interface
* **Desafio 3** — aplicação de conceitos de layout e responsividade
* **Desafio 4** — consolidação dos conhecimentos adquiridos

Cada desafio possui sua própria implementação e pode ser visualizado diretamente pelo GitHub Pages.

## 🚀 Tecnologias

* HTML5
* CSS3

## 💡 Aprendizados

Este projeto representa uma etapa importante da minha evolução no desenvolvimento Front-end.

Foi durante a realização desses desafios que passei a compreender CSS de maneira mais prática, deixando de apenas conhecer propriedades isoladas e passando a entender como utilizá-las para construir layouts e interfaces completas.

O conhecimento adquirido aqui serviu como base para projetos posteriores envolvendo desenvolvimento web, React e TypeScript.
